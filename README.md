# AWS S3 Bucket Website Hosting Assignment

This project is a simple static website developed using HTML, CSS, and JavaScript and deployed on Amazon S3 using AWS Cloud services.

---

# 🚀 Project Objective

The objective of this assignment is to understand:

- Cloud Computing concepts
- Static website hosting
- Deployment process on AWS Cloud
- AWS S3 bucket configuration
- Public website deployment

---

# 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Amazon Web Services (AWS S3)

---

# 📂 Project Features

- Responsive web design
- Interactive UI using JavaScript
- Static website hosting on AWS S3
- Publicly accessible live website

---

# 🌐 Live Website Link

🔗 http://portfolioshri14.s3-website-us-east-1.amazonaws.com/

---

# ☁️ AWS Deployment Steps

1. Created an AWS S3 Bucket  
2. Uploaded website source files  
3. Enabled Static Website Hosting  
4. Configured Bucket Policy for public access  
5. Disabled Block Public Access settings  
6. Generated live website endpoint
